This branch (`community-versions`) stores versions of [user-thoughts.SKILL](https://github.com/JularDepick/user-thoughts.SKILL) submitted to various community skill repositories. Each community version is adapted to meet the target community's specification and format requirements.
- Community versions are copies of this SKILL that have been optimized through the community's automated and approval processes and placed into the community repository source
- Community versions are more standardized, but may lag behind the source repository version; the source repository version is more up-to-date, but may not be as standardized as community versions
