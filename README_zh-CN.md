本分支 (`community-versions`) 存储 [user-thoughts.SKILL](https://github.com/JularDepick/user-thoughts.SKILL) 提交到各个社区技能仓库的版本。每个社区版本均根据目标社区的规范和格式要求进行了适配。
- 社区版本系指本SKILL提交到社区仓库后，经社区自动化和审批流程优化并放入社区仓库源码的副本
- 社区版本更规范化，但版本可能落后于源仓库版本；源仓库的版本更先进，但规范性可能比不上社区版本
